# S3

Steps for interacting with S3-compatible object storage (MinIO, LocalStack, AWS)

!!! tip "Multi-line Content"
    Steps ending with `:` accept multi-line content using Gherkin's docstring syntax (`"""`). See examples below each section.


## Bucket Setup

| Step | Description |
|------|-------------|
| `"uploads-storage" bucket "uploads" exists` | Create a bucket if it does not already exist |
| `"uploads-storage" bucket "uploads" is empty` | Delete every object in a bucket |
| `"uploads-storage" bucket "uploads" is deleted` | Delete a bucket and everything in it |



## Object Setup

| Step | Description |
|------|-------------|
| `"uploads-storage" object "uploads/hello.txt" is "hello world"` | Write an object with inline content (path is bucket/key) |
| `"uploads-storage" object "uploads/user.json" is:` | Write an object with multiline content (docstring) |
| `"uploads-storage" object "uploads/a.csv" is "id,name" with content type "text/csv"` | Write an object with an explicit content type |
| `"uploads-storage" object "uploads/a.csv" is "id,name" with metadata:` | Upload an object with user metadata (table of key | value) |
| `"uploads-storage" object "uploads/logo.png" is file "testdata/logo.png"` | Upload a local file as an object |
| `"uploads-storage" object "uploads/hello.txt" is deleted` | Delete a single object |
| `"uploads-storage" objects:` | Seed multiple objects from a table with path and content columns |


### Examples

**Write an object with multiline content (docstring):**
```gherkin
"uploads-storage" object "uploads/user.json" is:
  """
  {"id": 1, "name": "John"}
  """
```

**Upload an object with user metadata (table of key | value):**
```gherkin
"uploads-storage" object "uploads/a.csv" is "id,name" with metadata:
  | key   | value   |
  | owner | billing |
```

**Seed multiple objects from a table with path and content columns:**
```gherkin
"uploads-storage" objects:
  | path                | content     |
  | uploads/a.txt       | first       |
  | uploads/b.txt       | second      |
```


## Bucket Assertions

| Step | Description |
|------|-------------|
| `"uploads-storage" bucket "uploads" should exist` | Assert a bucket exists |
| `"uploads-storage" bucket "temp" should not exist` | Assert a bucket does not exist |
| `"uploads-storage" bucket "uploads" should have "3" objects` | Assert the object count in a bucket |
| `"uploads-storage" bucket "uploads" should be empty` | Assert a bucket holds no objects |
| `"uploads-storage" bucket "uploads" should have "2" objects with prefix "2026/"` | Assert the object count under a key prefix |
| `"uploads-storage" bucket "uploads" should have "1" objects within "10s"` | Wait for a bucket to reach an object count (async writes) |



## Object Assertions

| Step | Description |
|------|-------------|
| `"uploads-storage" object "uploads/hello.txt" should exist` | Assert an object exists |
| `"uploads-storage" object "uploads/gone.txt" should not exist` | Assert an object does not exist |
| `"uploads-storage" object "uploads/report.pdf" should exist within "10s"` | Wait for an object to appear (async writes) |
| `"uploads-storage" object "uploads/hello.txt" content should be "hello world"` | Assert exact object content |
| `"uploads-storage" object "uploads/hello.txt" content should be:` | Assert exact object content (docstring) |
| `"uploads-storage" object "uploads/log.txt" content should contain "ERROR"` | Assert object content contains a substring |
| `"uploads-storage" object "uploads/user.json" content should match:` | Assert object JSON content matches (partial, supports @matchers) |
| `"uploads-storage" object "uploads/hello.txt" size should be "11" bytes` | Assert object size in bytes |
| `"uploads-storage" object "uploads/a.csv" content type should be "text/csv"` | Assert object content type |
| `"uploads-storage" object "uploads/a.csv" metadata "owner" should be "billing"` | Assert a user metadata value on an object |


### Examples

**Assert exact object content (docstring):**
```gherkin
"uploads-storage" object "uploads/hello.txt" content should be:
  """
  hello world
  """
```

**Assert object JSON content matches (partial, supports @matchers):**
```gherkin
"uploads-storage" object "uploads/user.json" content should match:
  """
  {"id": "@number", "name": "John"}
  """
```
